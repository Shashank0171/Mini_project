1. Abstract

This project presents an AI-based mobile assistant designed to empower visually impaired individuals with real-time environmental awareness. The system leverages YOLOv8 for object detection, BLIP for scene description, Google ML Kit for text recognition (OCR), and OpenStreetMap for GPS navigation — all accessible through voice commands in English, Telugu, and Hindi.

The mobile application is built using Flutter for cross-platform compatibility and communicates with a FastAPI Python backend that hosts the AI models. The app features continuous real-time object tracking, voice-guided navigation, emergency SOS with direct calling, and a fully accessible UI designed for users with visual impairments.

Currently implemented as a software solution (mobile app), this system is designed to be extended to smart glasses (for hands-free AI vision) and a smart stick (for obstacle detection via ultrasonic sensors) in future hardware iterations.

2. Introduction

According to the World Health Organization (WHO), approximately 2.2 billion people worldwide have vision impairment. In India alone, over 12 million people are blind. These individuals face significant challenges in daily activities such as identifying objects, reading text, navigating unfamiliar environments, and responding to emergencies.

Traditional assistive tools like white canes and guide dogs provide limited information about the environment. With advances in artificial intelligence, computer vision, and mobile computing, it is now possible to build intelligent systems that can "see" for the user and communicate information through voice.

This project develops an AI-powered mobile assistant that acts as a digital companion for visually impaired individuals. The system uses the smartphone's camera to detect objects, read text, and describe scenes — converting visual information into speech output in the user's preferred language.

Motivation

  • Existing solutions are either too expensive or limited in functionality
  • Smartphones are widely accessible, even to visually impaired users
  • Modern AI models can run efficiently on mobile devices or lightweight servers
  • Multilingual support is essential for Indian users
  • The software can later be integrated with hardware (smart glasses + smart stick)

7. Features & Modules

👁️

1. Real-Time Object Detection

Always-on camera tracking using YOLOv8. Captures frames every 2.5s, detects objects (persons, vehicles, furniture, electronics, etc.), and announces them via speech. Only speaks when detected objects change to avoid repetition. Supports pause/resume tracking.

📖

2. Text Reader (OCR)

Captures text from camera using Google ML Kit's on-device text recognition. Works offline. Reads signs, labels, documents, medicine names, etc. Output is spoken aloud in the user's language.

🌄

3. Scene Description

Uses BLIP (Salesforce) to generate natural language descriptions of the entire scene. Example: "A person sitting at a desk with a laptop computer." Helps users understand their complete surroundings.

🧭

4. GPS Navigation

Voice-guided turn-by-turn navigation using OpenStreetMap and OSRM routing engine. Place search via Nominatim. No Google Maps dependency. Provides distance, duration, and step-by-step voice instructions.

🆘

5. Emergency SOS

One-tap SOS button that directly calls the emergency contact. Users can add multiple emergency contacts with name, phone, and relationship. Pulsing animated button for quick access.

⚙️

6. Settings & Accessibility

Language selection (EN/TE/HI), speech rate control, large text mode, high contrast mode, voice feedback toggle, emergency contact management. All settings persist locally.

8. AI Models Used

8.1 YOLOv8 — Object Detection

Model: YOLOv8n (Nano) by Ultralytics
Task: Real-time object detection
Classes: 80 COCO categories (person, car, chair, phone, laptop, etc.)
Speed: ~40ms per image on CPU (MacBook M-series)

YOLO (You Only Look Once) v8 is a state-of-the-art single-shot object detector. Unlike two-stage detectors, YOLOv8 processes the entire image in one forward pass, making it extremely fast for real-time applications. The model outputs bounding boxes with class labels and confidence scores.

How it works in our app:

  1. Camera captures frame → sent as multipart image to backend
  2. FastAPI receives image → passes to YOLOv8 model
  3. Model detects objects → returns list of {name, confidence}
  4. App filters by confidence threshold (≥50%)
  5. Results converted to speech: "I can see a person and a laptop"

8.2 BLIP — Scene Description

Model: Salesforce/blip-image-captioning-base
Task: Image-to-text captioning
Architecture: Vision Transformer + Language Model
Output: Natural language scene description

BLIP (Bootstrapping Language-Image Pre-training) uses a Vision Transformer to understand image content and a language model to generate descriptive captions. It was trained on millions of image-text pairs and can describe complex scenes naturally.

8.3 Google ML Kit — OCR

Model: Google ML Kit Text Recognition
Task: Optical Character Recognition
Runs: On-device (no internet needed)
Languages: Latin script (English) + Devanagari (Hindi)

ML Kit uses deep learning models optimized for mobile devices to detect and recognize text in images. It runs entirely on-device for privacy and speed.

9.2 YOLOv8 Detection Service

# services/detection_service.py
from ultralytics import YOLO

class DetectionService:
    _instance = None
    
    def __init__(self):
        self.model = YOLO("yolov8n.pt")  # Auto-downloads
        self.confidence_threshold = 0.5
    
    def detect(self, image_path: str):
        results = self.model(image_path)
        detections = []
        for result in results:
            for box in result.boxes:
                conf = float(box.conf[0])
                if conf >= self.confidence_threshold:
                    cls = int(box.cls[0])
                    name = result.names[cls]
                    detections.append({
                        "name": name, 
                        "confidence": round(conf, 2)
                    })
        return detections

11. Setup & Installation

Prerequisites

  • Flutter SDK 3.44+
  • Python 3.10+
  • Android SDK 36
  • 8GB+ RAM (for AI models)

Backend Setup

cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000

YOLOv8 model auto-downloads on first run (~6MB). BLIP model downloads from HuggingFace (~1GB).

Flutter App Setup

cd ai_mobile_assistant
flutter pub get
# Update apiBaseUrl in lib/utils/constants.dart
flutter build apk --debug
# APK at: build/app/outputs/flutter-apk/app-debug.apk

Connecting App to Backend

Both devices must be on the same WiFi. Set apiBaseUrl to your computer's IP address (e.g., http://192.168.0.102:8000).
